## v1 (MVP)

### 1. 타이머
- [x] 모드 탭: 🎯 집중 / ☕ 짧은 휴식 / 🌿 긴 휴식 (탭을 눌러 직접 전환도 가능)
- [x] 버튼: ↺ 리셋, ▶ 시작/일시정지, ⏭ 다음 세션
- [x] 집중 N회마다 긴 휴식 (기본 4회)
- [x] 남은 시간을 브라우저 탭 제목에 표시 (예: `18:42 · 집중`)
- [x] 리셋이나 건너뛰기로 끝난 집중은 완료로 세지 않음

### 2. 설정
- [ ] 각 모드 시간(분)
- [ ] 긴 휴식 주기 (N회)
- [ ] 휴식 자동 시작 / 집중 자동 시작 (기본 꺼짐)
- [ ] 브라우저 알림 켜기
- [ ] 데이터 초기화

### 3. 할 일
- [x] 할 일 추가, 수정, 삭제, 완료 체크
- [x] 지금 집중할 할 일 하나 선택
- [x] 집중 완료 시 선택한 할 일의 뽀모도로 개수 +1
- [x] (선택) 할 일마다 예상 뽀모도로 개수 입력 → `2 / 4` 처럼 표시

### 4. 알림
- [ ] 세션 종료 시 알림 소리
- [ ] 브라우저 알림 (허용한 경우)
- [x] 완료 팝업 + 다음 단계 버튼 (예: "수고했어요! ☕ 짧은 휴식 →")

### 5. 오늘 기록
- [x] 오늘 완료한 세션 수, 집중한 시간(분)
- [x] 날짜가 바뀌면 오늘 기록은 새로 시작 (지난 기록은 v1.5 통계를 위해 날짜별로 보관)

### 6. 사용성
- [ ] 단축키: `Space` 시작/일시정지, `R` 리셋, `N` 다음, `S` 설정
- [x] 다크 / 라이트 모드 (기본값은 시스템 설정을 따름)
- [ ] 반응형 (휴대폰 화면 지원)
- [ ] 타이머 진행 중 화면 꺼짐 방지 (Screen Wake Lock, 지원 브라우저에서만)
- [ ] 언어: 한국어

### 화면 구성 (시안, 2026-11-07)

한 페이지에 타이머와 할 일을 함께 둡니다. PC(1024px 이상)는 왼쪽 타이머, 오른쪽 할 일 2단, 휴대폰은 위아래로 쌓습니다.

- **상단**: 로고(🐾 까미도로) / 오늘 기록(🐾 3개 · 75분, 좁은 화면에선 숨김) / 다크 모드 버튼 / 설정 버튼
- **타이머 카드**
  - 모드 탭: 집중 / 짧은 휴식 / 긴 휴식
  - 까미 사진: 160px 원형, 모드에 따라 사진이 바뀜
  - 남은 시간: 화면에서 가장 크게, 숫자 폭 고정(tabular-nums)
  - 상태 문구: "집중할 시간이에요" / "까미랑 짧은 산책 시간이에요", 집중 중엔 "지금 할 일"
  - 버튼: 리셋 · 시작/일시정지(가장 크게) · 다음 세션
  - 사이클 표시: 발자국 4개 중 완료한 만큼 색칠, "긴 휴식까지 N번 남았어요"
- **할 일 카드**: 입력칸 + 추가 버튼, 목록(체크박스, 집중 중 표시, 🐾 완료/예상 개수, 수정, 삭제)
- **모드별 색**: 배경과 버튼, 탭, 선택된 할 일이 모드 색(집중 빨강, 짧은 휴식 초록, 긴 휴식 파랑)으로 바뀜
- **브라우저 탭 제목**: `24:13 · 집중 | 까미도로`

### 진행 상황

- 2026-11-07: 타이머 로직(테스트 29개), 저장, 타이머 화면, 오늘 기록 완료.
- 2026-11-07: 까미 사진, 완료 팝업, 5초 테스트 모드 추가.
- 2026-11-07: 1단계 다크 모드 버튼, 2단계 할 일 목록 완료. 다음: 3단계 알림 → 4단계 설정 → 5단계 단축키, 화면 꺼짐 방지 → 6단계 까미 수료증

### 7. 까미 수료증 (2026-11-07 추가)
- [ ] 한 사이클(집중 4번, 긴 휴식 주기 설정을 따름)을 모두 마치면 수료증 받기
- [ ] 화려한 이미지: 인스타그램 스토리 비율(1080x1920), 까미 사진, 날짜, 완료한 뽀모도로 수와 집중 시간, 집중한 할 일, 까미 도장
- [ ] 휴대폰: 공유하기(Web Share API)로 인스타그램 등에 바로 공유 / PC: 이미지 저장
- 웹에서는 인스타그램에 직접 올릴 수 없어서, 기기의 공유 창이나 저장한 이미지를 통해 올림

### MVP 완료 기준
- [ ] 집중 → 휴식 → … → 긴 휴식 사이클이 설정대로 돈다
- [ ] 다른 탭에 있어도 시간이 틀어지지 않고, 끝나면 알림이 온다
- [ ] 할 일을 골라 집중하면 그 할 일에 뽀모도로가 쌓인다
- [ ] 새로고침해도 설정, 할 일, 오늘 기록, 진행 중인 타이머가 유지된다
- [ ] 인터넷 주소로 접속해서 PC와 휴대폰에서 쓸 수 있다

## 서버가 필요한 기능 후보

MVP는 서버 없이 동작합니다. 아래 기능을 하게 되면 서버(또는 Supabase 같은 BaaS)가 필요합니다.

| 기능 | 서버가 하는 일 | 시기 |
|---|---|---|
| 로그인 + 여러 기기 동기화 | 계정, 할 일, 기록, 루틴 저장 | v2 이후 |
| 화면이 꺼져도 정시 알림 (웹 푸시) | 푸시 구독 저장, 종료 시각에 푸시 발송 예약 | v3 |
| 함께 집중하기 (친구와 같은 타이머) | 실시간 상태 공유 | 아이디어 |
| 루틴 템플릿 공유 | 다른 사람이 만든 루틴 저장, 검색 | 아이디어 |
| 랭킹, 친구 기록 비교 | 여러 사용자 기록 집계 | 아이디어 |

## 기술적으로 주의할 점

- **시간 계산**: 1초씩 빼지 않고 "종료 예정 시각"을 저장해서 `종료 시각 - 현재 시각`으로 계산. 백그라운드 탭에서도 정확하고 새로고침해도 이어서 진행 가능.
- **알림 소리**: 브라우저는 사용자가 클릭하기 전에는 소리 재생을 막음 → 시작 버튼을 누를 때 오디오를 준비.
- **기록 저장 구조**: 처음부터 세션을 날짜와 함께 기록해 두어야 v1.5 통계를 만들 수 있음.
