## 다음 개발 순서 (2026-11-08)

MVP(1~6단계) 이후 순서. 각 항목은 시작할 때 세부 사항을 정하고, 시안이 필요한 화면은 시안부터 봅니다.

| 순서 | 항목 | 왜 이 순서인지 |
|---|---|---|
| 1 | **UI 개선: 한 화면에 들어가게** + 페이지 이동 구조 | 기능을 더 얹기 전에 화면 틀부터 정리. 캘린더 페이지로 가는 메뉴도 이때 만듦 |
| 2 | **캘린더 페이지**: 날짜별 수료 인증, 할 일 달성/진행 중 표시 | 새 화면 틀 위에 만듦. 서버 없이 지금 기록으로 가능. 할 일·기록 저장 방식을 여기서 확정 |
| 3 | **집중 소리**: 집중하는 동안 나오는 소리 (1단계 완료) | 다른 기능과 독립적. 새 화면에 조절 버튼 자리를 잡은 뒤 만듦 |
| 4 | **공개 준비, 배포**: GitHub, 로고·파비콘, 링크 미리보기, Vercel | 로그인은 고정된 HTTPS 주소가 있어야 실제로 쓸 수 있음 (로그인 서비스 등록, 돌아올 주소) |
| 5 | **로그인 + 여러 기기 동기화** | 서버(또는 BaaS)가 생기는 가장 큰 작업. 저장 구조가 1~4에서 안정된 뒤에 옮겨야 다시 하는 일이 적음 |
| 6 | 그 밖: 통계(2026-11-08 완료, 캘린더 페이지 맨 위), 업적 배지 + 수료증 칭호, PWA, 루틴 | 앞의 결과에 맞춰 순서 다시 정함 |

### 1. UI 개선 (한 화면에 들어가게)
- 확인한 현상 (할 일 3개 기준, 2026-11-08)
  - 노트북 1366×768: 65px 넘쳐서 사이클 표시가 잘림
  - 휴대폰(아이폰 13 기준 화면 높이 664): 페이지가 1152px로 약 1.7화면. 할 일 목록은 스크롤해야 보임
  - 1440×900 이상 PC는 한 화면에 들어감
- [x] "지금 할 일" 줄을 없애고, 집중 중에는 상태 문구 자리에 할 일 칩(🐾 할 일 제목, 길면 …)을 보여줌. 일시정지 중에는 "잠시 멈췄어요"
- [x] 사이클 표시를 2줄로: 발자국 / "긴 휴식까지 N번 남았어요" ("이번 사이클" 제목 없앰)
- [x] "오늘 N사이클 완료" 배지를 헤더의 🏅 숫자 버튼으로 옮김 (누르면 수료증, 휴대폰에서도 보임)
- [x] 화면 높이에 맞춰 사진, 시간 글자, 여백이 줄어듦 → 노트북 1366×768은 한 화면, 휴대폰(아이폰 SE~13)은 타이머 카드 전체가 첫 화면에 들어감
- 휴대폰의 할 일은 지금처럼 타이머 아래로 스크롤 (탭으로 나누지 않음)
- [x] 페이지 이동 메뉴(타이머 / 캘린더): 헤더 로고 옆 글자 탭. 좁은 휴대폰에서는 로고 글자를 숨기고 발자국만
- [x] **할 일 순서 바꾸기**(아래 6-3)
- [x] 헤더 오른쪽 정리 (백로그 I-011, 2026-11-08): 오늘 기록 · 🏅 · 🎧 · ☰ 메뉴. 다크 모드 스위치, 설정, 사용법을 메뉴 안으로

### 2. 캘린더 페이지 (2026-11-08 완료)
- [x] 월 달력(`/calendar`): 집중 횟수에 따라 칸 색이 진해짐(4단계), 사이클을 마친 날은 🏅. 이번 달 합계, 이전/다음 달, "오늘" 버튼
- [x] 날짜를 누르면 상세: 집중 횟수·시간·사이클, 그날 마친 사이클마다 "제 N호 수료증"(지난 수료증 다시 만들기), 완료한 할 일, 진행 중이던 할 일 (할 일마다 그날 🐾 횟수)
- [x] "완료한 할 일 지우기" → "완료한 할 일 정리": 지우지 않고 목록에서만 숨김. 캘린더에는 남음
- [x] 집중 기록에 할 일 제목도 저장 → 할 일을 지워도 캘린더, 수료증에 제목이 남음
- [x] 다른 페이지에 있어도 타이머 알림, 완료 팝업, 탭 제목의 남은 시간이 동작
- 등록일 표시는 하지 않음 (캘린더의 완료한 날짜로 충분). 필요하면 다시 검토

### 3. 집중 소리 (2026-11-08 1단계 완료)
- 기존 계획의 "배경음"을 이 항목으로 바꿈
- [x] 헤더 🎧 버튼 → 펼침 창에서 소리 고르기, 소리 크기. 집중 중에만 재생, 휴식·일시정지 때 서서히 꺼짐. 기본은 꺼짐
- [x] 노이즈 3종(백색, 핑크, 브라운): 브라우저에서 만듦 (파일 없음)
- [x] 자연의 소리 5종(빗소리, 창가 빗소리, 모닥불, 숲속, 파도): Pixabay 녹음을 다듬어 넣음, 처음 고를 때 받음
- [ ] 2단계(필요하면): 음악(로파이 등) 몇 곡

### 5. 로그인 + 동기화
- 정할 것: 로그인 방법(구글, 카카오 등), 서비스(Supabase / Firebase 등), 로그인 전 브라우저에 쌓인 데이터를 계정으로 옮기는 방법, 탈퇴와 데이터 삭제
- 개인정보를 받게 되므로 개인정보처리방침 페이지가 필요함
- 로그인 없이도 지금처럼 쓸 수 있게 유지할지 결정 (추천: 유지)
- 수료증에 이름 넣기 검토

### 6. 통계 (2026-11-08 완료)
- 따로 탭을 만들지 않고 캘린더 페이지 맨 위에 "통계" 카드로 넣음 (PC는 왼쪽 요약 칸, 오른쪽 막대 / 휴대폰은 요약 칸 아래 막대)
- [x] 연속 일수(🔥)와 최고 기록. 오늘 아직이면 "오늘 집중하면 N일째"
- [x] 최근 7일 집중 시간 + 그 전 7일과 비교
- [x] 이번 달 집중 시간, 사이클 수
- [x] 전체 집중 횟수, 시간, 사이클 수
- [x] 최근 7일 막대 (하루 집중 시간, 분. 오늘 강조)
- [x] 기록이 없으면 까미와 안내 문구

### 1. 타이머
- [x] 모드 탭: 🎯 집중 / ☕ 짧은 휴식 / 🌿 긴 휴식 (탭을 눌러 직접 전환도 가능)
- [x] 버튼: ↺ 리셋, ▶ 시작/일시정지, ⏭ 다음 세션
- [x] 집중 N회마다 긴 휴식 (기본 4회)
- [x] 남은 시간을 브라우저 탭 제목에 표시 (예: `18:42 · 집중`)
- [x] 리셋이나 건너뛰기로 끝난 집중은 완료로 세지 않음
- [x] 시작한 집중을 ⏭로 건너뛰거나 리셋할 때는 한 번 확인 (휴식, 시작 전 세션은 바로 실행)

- [x] 띠 효과 켜기/끄기

- [x] 언어: 한국어

### 화면 구성 (시안, 2026-11-07)

한 페이지에 타이머와 할 일을 함께 둡니다. PC(1024px 이상)는 왼쪽 타이머, 오른쪽 할 일 2단, 휴대폰은 위아래로 쌓습니다.

- **상단**: 로고(🐾 까모도로) / 오늘 기록(🐾 3개 · 75분, 좁은 화면에선 숨김) / 다크 모드 버튼 / 설정 버튼
- **타이머 카드**
  - 모드 탭: 집중 / 짧은 휴식 / 긴 휴식
  - 까미 사진: 원형, 모드에 따라 사진이 바뀜. 사진 둘레에 진행 띠(12시에서 시계 방향으로 지난 시간이 흐려지고, 남은 시간은 모드 색)
  - 남은 시간: 화면에서 가장 크게, 숫자 폭 고정(tabular-nums)
  - 상태 문구: "집중할 시간이에요" / "까미랑 짧은 산책 시간이에요", 집중 중엔 "지금 할 일"
  - 버튼: 리셋 · 시작/일시정지(가장 크게) · 다음 세션
  - 사이클 표시: 발자국 4개 중 완료한 만큼 색칠, "긴 휴식까지 N번 남았어요"
- **할 일 카드**: 입력칸 + 추가 버튼, 목록(체크박스, 집중 중 표시, 🐾 완료/예상 개수, 수정, 삭제)
- **모드별 색**: 배경과 버튼, 탭, 선택된 할 일이 모드 색(집중 빨강, 짧은 휴식 초록, 긴 휴식 파랑)으로 바뀜
- **브라우저 탭 제목**: `24:13 · 집중 | 까모도로`

## 서버가 필요한 기능 후보

MVP는 서버 없이 동작합니다. 아래 기능을 하게 되면 서버(또는 Supabase 같은 BaaS)가 필요합니다.

| 기능 | 서버가 하는 일 | 시기 |
|---|---|---|
| 로그인 + 여러 기기 동기화 | 계정, 할 일, 기록, 루틴 저장 | 다음 개발 순서 5번 |
| 화면이 꺼져도 정시 알림 (웹 푸시) | 푸시 구독 저장, 종료 시각에 푸시 발송 예약 | v3 |
| 함께 집중하기 (친구와 같은 타이머) | 실시간 상태 공유 | 아이디어 |
| 루틴 템플릿 공유 | 다른 사람이 만든 루틴 저장, 검색 | 아이디어 |
| 랭킹, 친구 기록 비교 | 여러 사용자 기록 집계 | 아이디어 |

## 기술적으로 주의할 점

- **시간 계산**: 1초씩 빼지 않고 "종료 예정 시각"을 저장해서 `종료 시각 - 현재 시각`으로 계산. 백그라운드 탭에서도 정확하고 새로고침해도 이어서 진행 가능.

- **기록 저장 구조**: 처음부터 세션을 날짜와 함께 기록해 두어야 v1.5 통계를 만들 수 있음.
