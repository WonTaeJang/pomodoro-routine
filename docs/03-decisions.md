# 결정 기록

개발하면서 내린 결정과 그 이유를 모아두는 문서입니다. 결정이 바뀌면 기존 내용을 고치고 "변경 이력"에 남깁니다.

## 결정됨

### 플랫폼: 웹 (2026-11-07)
- **이유**: 가장 빠르게 만들어 바로 쓸 수 있고, 스토어 비용과 심사가 없음.
- **검토했던 대안**: 처음부터 앱(Expo, Flutter, 네이티브). 앱은 화면이 꺼져도 서버 없이 정시에 알림이 울리는 장점이 있지만, 스토어 비용(Apple 연 $99, Google 1회 $25), 심사, Google Play 신규 계정의 비공개 테스트(테스터 12명, 14일) 부담이 있음.
- **나중에 앱이 필요해지면**: 웹 코드를 Capacitor로 앱으로 포장하고 로컬 알림을 추가.

### 휴대폰 지원: 반응형 + 화면 꺼짐 방지 (2026-11-07)
- 휴대폰 화면 대응은 **반응형 디자인(CSS)** 으로 함. PWA와는 별개.
- 휴대폰은 화면이 꺼지거나 다른 앱으로 넘어가면 웹페이지 실행을 멈춤 → 종료 알림이 제때 안 울릴 수 있음. 그래서 MVP는 "화면을 켜둔 채로 쓰는" 경우를 기본으로 보고, 타이머 진행 중 **Screen Wake Lock**으로 화면 꺼짐을 막음.
- 남은 시간은 종료 시각 기준으로 계산하므로 다시 돌아오면 정확하게 보임.

### PWA: v1.5에서 적용 (2026-11-07)
- 얻는 것: 홈 화면 설치, 주소창 없는 앱 화면, 오프라인 실행, **iPhone 알림**(iOS는 홈 화면에 설치한 웹앱에만 알림 허용, iOS 16.4 이상).
- PWA로도 화면 꺼진 상태의 정시 알림은 해결되지 않음. 해결하려면 서버 푸시가 필요 → 검토 대상(v3 이후).

### 계정: 로그인 없음, 브라우저 저장 (2026-11-07) → 로그인 추가 예정 (2026-11-08)
- 설정, 할 일, 기록은 localStorage에 저장. 참고 사이트와 같은 방식으로 진입 장벽을 없앰.
- 2026-11-08: 로그인과 여러 기기 동기화를 개발하기로 함. 순서는 UI 개선, 캘린더, 집중 음악, 배포 다음 (02-mvp-scope.md "다음 개발 순서").
  - 고정된 HTTPS 주소가 있어야 로그인 서비스를 실제로 연결할 수 있어서 배포 뒤에 함.
  - 로그인 방법, 서비스(Supabase / Firebase 등), 기존 브라우저 데이터 옮기기는 시작할 때 결정. 로그인 없이 쓰는 방식은 유지하는 쪽으로 검토.

### 기술 스택: Next.js + TypeScript (2026-11-07)
- **이유**: 나중에 로그인, 웹 푸시, 함께 집중하기 같은 서버 기능을 같은 프로젝트 안에서 만들 수 있고, 공개 서비스일 때 검색 노출과 Vercel 배포에 유리함.
- **주의**: 타이머, 할 일 화면은 클라이언트 컴포넌트(`"use client"`)로 만듦. localStorage 값(설정, 테마)이 첫 화면에서 서버 렌더링과 달라 깜빡이는 문제(hydration 불일치)를 처음부터 처리함.
- **검토했던 대안**: React + Vite. MVP만 보면 더 가볍지만, 서버 기능을 붙일 때 별도 서버나 BaaS가 필요함.

### 스타일: SCSS 직접 작성 (2026-11-07)

### 타이머 세부 규칙 (2026-11-07)
- 남은 시간은 "끝나는 시각 - 현재 시각"으로 계산. 다른 탭에 있거나 새로고침해도 정확함.
- 집중 완료 → 짧은 휴식. 이번 사이클 집중이 긴 휴식 주기(기본 4)에 닿으면 긴 휴식. 긴 휴식이 끝나거나 건너뛰면 사이클 처음부터.
- **리셋, 건너뛰기, 모드 탭 전환은 완료로 세지 않음.** 진행 중이거나 멈춘 세션이 있을 때 모드 탭을 누르면 확인 팝업을 띄움.
- 자동 시작이 켜져 있으면 완료 팝업에서 **5초를 센 뒤** 다음 세션이 시작됨 (2026-11-08, 백로그 I-002). 처음에는 이전 세션이 끝난 시각부터 바로 이어서 진행했음.
  - 5초는 팝업이 실제로 보인 순간부터. 다른 탭에 있거나 자리를 비우면 돌아올 때까지 기다림. "지금 시작" / "취소"(X·Esc도 취소).
  - **사이클을 마친 순간(긴 휴식 차례)은 자동 시작하지 않음** (백로그 I-004). 수료증과 완료 팝업을 먼저 보게 함.
- 설정 창, 수료증 창을 보는 중에 세션이 끝나면 완료 팝업은 그 창을 닫을 때까지 기다렸다가 뜸 (백로그 I-003). 브라우저 팝업은 나중에 연 것이 항상 위에 그려져서, 보고 있던 창을 덮지 않도록.
- **자리를 비운 사이 끝난 경우**: 끝난 세션 1개만 완료로 기록. 다음 세션까지 이미 끝났을 시간이면 시작 전 상태로 둠 (자리를 비운 동안 뽀모도로가 저절로 쌓이지 않게).
- 설정을 바꾸면 시작 전 세션에만 바로 반영. 진행 중인 세션은 그대로.
- 끝까지 마친 세션은 모두(휴식 포함) 날짜와 함께 기록. "오늘"은 기기 시간 기준 자정부터.

### 까미 사진 사용 (2026-11-07)
- 화면의 원형 사진(160px)이 상황에 따라 바뀜: 시작 전 `kkami-default`(정면), 집중 중 `kkami-focus`(엎드려 쉬는 모습), 짧은 휴식 `kkami-short-break`(산책), 긴 휴식 `kkami-long-break`(신난 얼굴), 완료 팝업 `kkami-done`(무지개 배경).
- 원본 중 얼굴이 잘 안 보이는 사진(누워 있는 모습)과 크리스마스 사진은 제외. 크리스마스 사진은 12월 시즌 테마 후보.
- **로고, 파비콘은 사진이 아닌 일러스트로** 나중에 제작 (작은 크기에서 사진은 까만 덩어리로 보임). 동그란 귀 실루엣이 뚜렷한 무지개 배경 사진을 바탕으로.

### 할 일 규칙 (2026-11-07)
- 첫 할 일은 자동으로 "집중 중"이 됨. 다른 할 일은 "선택" 버튼으로 바꿈.
- 집중을 끝까지 마치면 그때 선택돼 있던 할 일에 🐾 +1. 세션 기록에도 할 일을 함께 저장(수료증, 통계용).
- 집중 중인 할 일을 완료하거나 지우면 남은 할 일 중 첫 번째가 자동 선택.
- 예상 뽀모도로 수는 1~20, 제목은 100자까지. 완료한 할 일은 목록 아래로.
- 할 일마다 **순서(order), 등록 시각(createdAt), 완료 시각(completedAt)** 을 저장. 완료를 취소하면 완료 시각은 지움. 순서는 추가할 때 맨 아래 번호가 붙고, 끌어서 다른 할 일 자리로 옮길 수 있음(같은 묶음 안에서만, 아래 "할 일 순서 바꾸기").
- 저장 형식이 바뀌면 `version`을 올리고 예전 데이터를 변환(migrate). 할 일은 v2부터 순서, 완료 시각 포함. 예전에 완료한 할 일의 완료 시각은 알 수 없어 비워 둠. v3부터 목록에서 숨긴 시각(archivedAt) 포함.
- "완료한 할 일 정리"는 완료한 할 일을 **지우지 않고 목록에서만 숨김**(archivedAt). 캘린더에는 계속 보임. 숨긴 할 일도 완료를 취소하면 다시 보임. 휴지통 버튼은 그대로 진짜 삭제. (2026-11-08)

### 까미 수료증 (2026-11-07)
- 한 사이클(긴 휴식 주기만큼 집중)을 모두 마치면 받음. MVP 마지막 단계(6단계)로 진행.
- 인스타그램 스토리 비율 이미지로 만들고, 휴대폰은 공유하기, PC는 저장.

### 사이클 완료 (2026-11-07)
- **4번째 집중(긴 휴식 주기)을 끝까지 마친 순간**을 사이클 완료로 봄. 긴 휴식을 끝까지 쉬었는지는 상관없음. 수료증을 받는 시점과 같음.
- 집중 횟수를 4로 나눠 계산하지 않고, 그 세션 기록에 `cycleCompleted`를 저장 (모드를 바꾸거나 건너뛴 경우에도 정확하게 세기 위함).
- 오늘 완료한 사이클 수는 상단 오늘 기록과 타이머 아래에 표시.

### 집중 후 할 일 완료 확인 (2026-11-07)
- 집중이 끝나면 완료 팝업에 그 집중의 할 일 카드를 보여주고 "이 할 일을 다 끝냈어요" 체크를 둠. 체크하면 바로 완료 처리되고 다음 할 일이 자동 선택됨. 다시 누르면 취소.
- 예상 개수를 채웠으면 "예상한 N번을 모두 채웠어요!"로 알려줌. 완료 여부는 사용자가 정함 (자동 완료하지 않음).

### 시간 표시 디자인 (2026-11-07)
- 시간 숫자는 지금처럼 큰 디지털 숫자로 유지. **아날로그 시계와 시계 모양 선택 기능은 만들지 않음.**
- 대신 까미 사진 둘레에 **원형 진행 띠**를 둠. 12시 방향에서 시작해 시계 방향으로 지난 시간만큼 흐려지고, 남은 부분은 모드 색으로 보임. 장식이므로 화면 낭독기에는 숨기고 남은 시간은 숫자로 전달.
- **띠 효과**: 집중을 방해하지 않도록 처음에는 차분하게, 끝에 가까울수록 살아나게 함.
  - 10%마다 발자국 도장 하나 (10%~90%, 9개): 발자국 수만 봐도 "몇 % 했는지" 알 수 있게. 까미가 원을 따라 걷는 방향으로 회전. 100%는 완료 효과가 대신함
  - 마지막 1분(세션이 5분보다 짧으면 전체의 20%): 띠 글로우 + 지금 위치에 빛나는 점
  - 집중 완료: 띠가 퍼지고 발자국·색종이가 터진 뒤 1초 후 완료 팝업. 한 사이클 완료면 더 크게
  - 마지막 10초 박동 효과는 넣지 않음
  - 움직임 줄이기 설정이면 움직임 없이 빛만 표시. 설정 화면에서 띠 효과를 끌 수 있음 (끄면 띠만 줄어들고 발자국, 빛, 완료 축하가 없음)

### 디자인 토큰과 공통 컴포넌트 (2026-11-07)
- 색, 간격, 글자, 모양, 움직임, 크기 값을 `src/styles/tokens/`의 CSS 변수로 모아 관리. 화면 코드에는 직접 값을 쓰지 않음 (한 컴포넌트 전용 값은 이름 붙인 Sass 변수로).
- 반복되던 카드와 배지를 `Card`, `Badge` 공통 컴포넌트로, 할 일의 🐾 개수 표시를 `PawCount`로 묶음. 커진 `TimerPanel`은 모드 탭, 버튼, 사이클 진행, 타이머 훅으로 나눔.
- 리팩터링 전후 주요 화면 8개를 고정된 시계와 데이터로 찍어 픽셀 비교 → 차이 0%.
- 상세 규칙은 [06-design-system.md](./06-design-system.md).

### 알림 소리와 브라우저 알림 (2026-11-07)
- **소리**: 오디오 파일 없이 Web Audio API로 종소리를 만듦. 집중 끝(도-미-솔), 휴식 끝(솔-도), 사이클 완료(도-미-솔-도 팡파레).
- **제때 울리게**: 시작할 때 끝나는 시각에 맞춰 소리를 **미리 예약**(오디오 시계는 숨긴 탭에서도 느려지지 않음). 끝나는 시각에는 반복 타이머가 아닌 **한 번만 실행되는 타이머**로 세션을 넘김(숨긴 탭에서 반복 타이머는 1분 단위로 늦어질 수 있음). 예약이 어긋났으면 세션이 끝난 걸 확인한 순간 울리고, 같은 세션에 두 번 울리지 않음.
- 일시정지, 리셋, 건너뛰기, 모드 변경 시 아직 울리지 않은 예약은 취소. 이미 울리기 시작한 소리는 끝까지 둠.
- **브라우저 규칙**: 소리는 사용자가 누른 뒤에만 낼 수 있어서 시작 버튼(또는 화면 아무 곳)을 누를 때 오디오를 깨움. 알림 권한은 **처음 시작 버튼을 누를 때 한 번** 물어봄.
- **브라우저 알림은 다른 탭에 있을 때만** 띄움. 화면을 보고 있으면 완료 팝업으로 충분.
- 알려진 제약
  - 안드로이드 크롬은 서비스 워커로만 알림을 띄울 수 있어 지금은 알림이 안 뜸 → v1.5 PWA에서 해결
  - iPhone은 무음 모드에서 웹 소리가 안 날 수 있음. 무음을 무시하는 설정(Audio Session `playback`)은 사용자가 듣던 음악을 멈출 수 있어 쓰지 않음
  - 화면이 꺼진 휴대폰에서는 웹페이지가 멈춰 제때 알릴 수 없음 (서버 푸시 필요, v3 검토)
- 설정 값(소리 켜기, 볼륨 0.7, 알림 켜기)은 저장해 두었고, 바꾸는 화면은 4단계에서 만듦.
- 예약·취소·중복 방지 규칙은 브라우저 기능과 분리한 `scheduler.ts`에 두고 단위 테스트로 검증. 화면 쪽 훅(`useAlerts`)은 연결만 함.

### 설정 화면 (2026-11-07)
- 헤더의 설정 버튼으로 여는 팝업. 따로 저장 버튼 없이 **바꾸는 즉시 저장, 적용**.
- 묶음: 타이머(시간, 긴 휴식 주기, 자동 시작) / 알림(소리, 소리 크기와 미리 듣기, 브라우저 알림) / 화면(테마, 띠 효과) / 데이터(설정 되돌리기, 모든 데이터 지우기).
- 시간은 숫자 입력칸 대신 − 값 + 버튼(Stepper)으로. 잘못된 값을 넣을 일이 없고 휴대폰에서도 누르기 쉬움. 집중, 긴 휴식은 5분 단위.
- 바꾼 시간은 **시작 전 세션에만 바로 적용**. 진행 중이면 "다음 세션부터 적용" 안내를 보여줌.
- 브라우저 알림이 차단돼 있으면 스위치를 꺼진 상태로 막고, 사이트 설정에서 허용하라고 안내.
- 소리를 켜는 순간 오디오를 깨움 (사용자가 누른 순간에만 소리를 낼 수 있음).
- **설정 되돌리기**: 시간, 알림, 화면 설정(테마 포함)만 처음 값으로. 할 일과 기록은 그대로.
- **모든 데이터 지우기**: 할 일, 기록, 설정, 테마, 진행 중이던 타이머를 모두 지움. 되돌릴 수 없어서 빨간 버튼 + 확인 팝업.
- 개발용 5초 테스트 모드는 주소로 켠 것이라 되돌리기·지우기 뒤에도 유지.

### 다음 세션(⏭) 버튼 확인 (2026-11-07)
- ⏭는 사이클 순서상 다음 세션으로 바로 넘어가는 버튼 (휴식 건너뛰고 바로 집중, 급한 일로 집중 일찍 접기 등).
- 시작했거나 멈춘 **집중**을 건너뛰면 그 시간이 기록 없이 사라지므로, 모드 탭처럼 한 번 확인함.
- 휴식, 시작 전 세션은 잃을 게 없어서 확인 없이 바로 넘어감.
- 확인 팝업(건너뛰기, 모드 탭 전환)을 띄운 사이 세션이 끝나거나 바뀌면 팝업을 자동으로 닫음. 그대로 확인하면 엉뚱한 세션(예: 방금 시작된 휴식)이 건너뛰어지기 때문 (`useSessionState`).

### 단축키, 화면 꺼짐 방지 (5단계, 2026-11-07 확정)
- **단축키**: `Space` 시작/일시정지, `R` 리셋, `N` 다음 세션, `S` 설정. 버튼과 똑같이 동작 (시작은 `startSession()`, `N`은 진행 중인 집중이면 확인).
  - 입력칸에 쓰는 중, Ctrl·⌘·Alt·Shift와 함께 누를 때, 팝업이 열려 있을 때, 키를 꾹 누르고 있을 때는 동작하지 않음.
  - `Space`와 포커스: 마우스로 ⏭ 등을 누르면 포커스가 그 버튼에 남아서, 브라우저 기본 동작대로면 `Space`가 그 버튼을 한 번 더 누름 (⏭로 휴식을 건너뛴 뒤 `Space`로 시작하려다 또 건너뜀). 그래서 **마우스로 생긴 포커스에서는 `Space` = 시작/일시정지**, **Tab·방향키로 골라 온 버튼·체크박스에서만 `Space`를 그 요소에 맡김** (키보드 사용자 접근성). 글자 단축키는 어디서든 동작.
  - 다른 기능이 이미 쓴 키는 단축키로 처리하지 않음. 예: 마우스로 할 일 손잡이를 누른 뒤 `Space` → 키보드로 옮기기만 시작되고 타이머는 그대로.
  - CSS `:focus-visible`은 키를 누르는 순간 키보드 쪽으로 바뀌어서 이 구분에 쓸 수 없음 → 포커스를 옮긴 수단을 직접 기록 (`focusSource.ts`).
  - 키보드가 없는 기기(터치만 되는 휴대폰)에서는 설정 창의 단축키 목록을 숨김.
  - 한글 자판 상태에서도 되도록 글자가 아닌 키 위치(`event.code`)로 판단.
  - 안내: 버튼에 마우스를 올리면 "시작 (Space)"처럼 보이고, 설정 창에 단축키 목록.
- **리셋 확인**: 리셋 버튼과 `R` 모두, 시작했거나 멈춘 **집중**일 때만 확인 팝업 (⏭와 같은 규칙).
- **화면 꺼짐 방지**(Screen Wake Lock): 타이머가 도는 동안(집중, 휴식 모두) 화면을 켜 둠. 멈추면 바로 풀고, 다른 탭에 갔다 돌아오면 다시 요청.
  - 설정 "화면" 묶음에 스위치, **기본 켜짐**. 지원하지 않는 브라우저면 스위치를 막고 안내.
  - PC는 화면 꺼짐·잠금·노트북 절전을 막고, 휴대폰은 화면이 꺼져 페이지가 멈추는 걸 막아 알림이 제때 울리게 함.
  - 지원: 크롬·엣지 84+, 사파리 16.4+, 파이어폭스 126+, 아이폰 iOS 18.4+. 지원하지 않으면 조용히 아무것도 안 함. 전원 버튼으로 직접 끄는 건 막을 수 없음.

### 까미 마스코트, 수료증 (6단계, 2026-11-07)
- **마스코트**: 까미 사진 대신 까미(검은 토이 푸들)를 바탕으로 직접 그린 SVG 마스코트를 씀. 특징: 검은 곱슬털, 둥글게 부푼 머리와 귀, 반짝이는 까만 눈, 분홍 혀, 파란 체크 턱받이와 데이지.
  - A 기본(턱받이) / B 수료증용(학사모 + 발자국 메달) / C 단순 아이콘(로고·파비콘 후보) 세 가지. 시안 확정.
- **수료증 이미지**: 인스타 스토리 크기 1080×1920 하나만. 브라우저 캔버스에 직접 그려 PNG로 만듦 (라이브러리, 서버 없이).
  - 디자인: **축하 카드** (토마토→분홍 그라데이션 배경 + 색종이, 흰 카드 위로 까미 B가 튀어나옴, 빨간 "까미 인증" 도장).
  - 스토리 위아래 약 250px는 인스타 화면에 가려지므로 중요한 내용은 그 안쪽에 둠.
  - 이름은 넣지 않음. 나중에 로그인 계정을 만들면 그때 이름을 넣는 걸 검토.
  - 이번 사이클에 한 할 일은 최대 3개 표시하고, 수료증 팝업에서 숨길 수 있게 함.
  - 공유: 휴대폰은 공유 창(Web Share), PC나 미지원 브라우저는 PNG 저장. 아이폰 사파리는 누른 순간에만 공유 창을 열 수 있어서 팝업이 열릴 때 이미지를 미리 만들어 둠.
- **수료증 내용**
  - 상단: "한 사이클 완료!" / 번호와 날짜: "제 12호 · 2026.11.07" (번호 = 지금까지 완료한 사이클 수)
  - 제목: **까모도로 수료증**
  - 본문(한 가지 문구 고정): "25분 집중을 4번 해내었기에 이 수료증을 드립니다." (25분, 4번은 설정값에 따라 바뀜)
  - 숫자 칸 3개: 이번 사이클 집중 시간 / 뽀모도로 수 / 오늘 완료한 사이클
  - 할 일이 없으면 할 일 목록 대신 "할 일 없이 오롯이 집중했어요"
  - 메달 배지로 나중에 다시 만들면 **가장 최근에 완료한 사이클**의 수료증
  - 칭호(누적 사이클에 따른 이름)는 다음 기능 업데이트에서 추가
  - 할 일을 숨기면 그 자리에 "오늘도 한 걸음 성장했어요"
  - 시간 표기: 1분 미만은 초, 1시간 이상은 "1시간 40분"
- **진입**: "한 사이클 완료!" 팝업의 "수료증 만들기" 버튼, 타이머 아래 "오늘 N사이클 완료" 메달 배지(누르면 열림).
- "할 일 보이기" 선택은 저장해 두고 다음에도 그대로 씀 (설정 되돌리기로 처음 값).
- 그리기 글꼴: 화면과 같은 Pretendard. 대체 글꼴(Arial 기반)이 없는 기기에서도 그릴 수 있게 글꼴 불러오기 실패는 무시.

### 타이머 화면 한 화면에 맞추기 (2026-11-08)
- 화면을 길게 만들던 "지금 할 일" 줄과 사이클 아래 "오늘 N사이클 완료" 배지를 없앰.
  - 지금 할 일 → 상태 문구 자리의 칩 (상태 문구와 할 일 중 하나만, 같은 높이라 바뀌어도 화면이 들썩이지 않음)
  - 오늘 사이클 수 → 헤더의 🏅 숫자 버튼 (헤더의 오늘 기록 배지에서는 사이클 수를 뺌, 겹치지 않게)
- 사진·진행 띠 지름 132~192px, 남은 시간 글자 3.5~7.5rem, 여백을 화면 높이(dvh)에 맞춰 조절. 진행 띠(`ProgressRing`)는 `--ring-display-size`로 크기를 바꿔도 도장 위치, 안쪽 사진 크기가 같은 비율로 따라감.
- 휴대폰에서 할 일을 탭으로 나누는 안은 쓰지 않음. 타이머 카드가 첫 화면에 다 들어가고 할 일은 아래로 스크롤.

### 할 일 순서 바꾸기: dnd-kit (2026-11-08)
- 끌어서 옮기기는 **dnd-kit**(`@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities`)을 씀. 마우스·터치·키보드를 한 방식으로 처리하고, 화면 낭독기 안내(한국어로 바꿈)를 지원함. 새 버전 `@dnd-kit/react`는 아직 1.0 전이라 쓰지 않음.
- 할 일 전체가 아니라 왼쪽 **손잡이(⠿)를 끌 때만** 움직임. 휴대폰에서 목록을 쓸어 스크롤하는 것과 겹치지 않게 하기 위함 (손잡이는 터치 스크롤을 막음). 4px 이상 움직여야 끌기 시작.
- 할 일과 완료한 할 일은 따로 묶어서 서로 섞이지 않음. 옮기면 그 묶음이 쓰던 순서 번호를 나눠 가져서, 완료를 취소한 할 일은 원래 순서 자리로 돌아감.
- 수정 중인 할 일은 손잡이가 없고 옮길 수 없음.
- "움직임 줄이기" 설정이면 다른 할 일이 미끄러지듯 비켜나는 움직임 없이 바로 자리를 바꿈.

### 캘린더 페이지 (2026-11-08)
- 주소 `/calendar`. 헤더 로고 옆에 "타이머 · 캘린더" 글자 탭 (지금 페이지는 진하게 + 밑줄). 좁은 휴대폰(480px 미만)에서는 로고 글자를 숨기고 발자국만.
- **달력 칸**: 숫자를 넣지 않고 집중 횟수에 따라 색이 진해짐 (1번, 3번, 5번, 8번 이상의 4단계, 아래 범례). 사이클을 마친 날은 🏅. 한 주는 일요일부터. 오늘은 안쪽 테두리, 고른 날은 바깥 테두리.
- **날짜 상세**: PC는 달력 오른쪽, 휴대폰은 달력 아래. 집중 횟수, 집중한 시간, 사이클 수, 그날 마친 사이클의 수료증 버튼, 완료한 할 일, 진행 중이던 할 일.
  - **완료한 할 일** = 그날 완료한 할 일 (집중 없이 완료한 것도).
  - **진행 중이던 할 일** = 그날 집중했지만 그날이 끝날 때까지 완료하지 않은 할 일. 다음 날 끝냈어도 그날은 진행 중으로 보임. "등록만 하고 안 끝난 할 일"은 끝낼 때까지 매일 보여서 쓰지 않음.
- **지난 수료증**: 사이클마다 번호(제 N호)로 다시 만들 수 있음. 숫자 칸 이름은 오늘 마친 사이클이면 "오늘 완료", 지난 사이클이면 "이날 완료".
- **기록에 할 일 제목 저장**: 집중 기록에 할 일 id와 함께 그때 제목(taskTitle)을 남김. 할 일을 지워도 캘린더, 수료증에 제목이 남음. 제목이 없는 예전 기록은 지금 남아 있는 할 일에서 제목을 찾음.
- **타이머는 모든 페이지에서 동작**: 시간이 되면 넘기기, 알림, 완료 팝업, 탭 제목, 화면 켜두기를 페이지 공통 틀(`AppShell`)로 옮김. 캘린더를 보는 중에 집중이 끝나도 팝업과 소리가 나옴. 단, Space·R·N 단축키는 타이머 화면에서만 (S 설정은 어디서나).
- 탭 제목은 `metadata`가 아니라 `<head>`에 직접 둠. `metadata`로 두면 페이지를 옮길 때 Next.js가 제목을 되돌려서 남은 시간이 사라짐.

### 집중 소리 (2026-11-08)
- **어디서**: 헤더의 🎧 버튼 → 아래로 펼쳐지는 창(브라우저 기본 popover. 바깥을 누르거나 ESC로 닫힘). 소리를 켜 두면 버튼에 점.
- **언제**: 집중이 진행 중일 때만. 일시정지, 휴식, 집중이 끝나면 서서히 꺼지고 다시 시작하면 서서히 켜짐. 다른 페이지(캘린더)에 있어도 들림. 기본은 꺼짐, 크기 50% (알림 소리 크기와 따로).
- **미리 듣기**: 집중 중이 아닐 때 소리를 고르면 4초 동안 들려줌 (녹음은 다 받은 뒤부터 4초). 집중 중에 고르면 바로 겹치며 바뀜.
- **노이즈 3종(백색, 핑크, 브라운)**: 파일 없이 브라우저에서 만듦. 양쪽 귀에 조금 다른 소리를 넣어 넓게 들리게 하고, 끝과 처음을 겹쳐 끊김 없이 반복.
- **자연의 소리 5종**: 처음엔 빗소리도 브라우저에서 만들었지만 인공적이라 실제 녹음으로 바꿈.
