# 결정 기록

개발하면서 내린 결정과 그 이유를 모아두는 문서입니다. 결정이 바뀌면 기존 내용을 고치고 "변경 이력"에 남깁니다.

## 결정됨

### 플랫폼: 웹 (2026-11-07)
- **이유**: 가장 빠르게 만들어 바로 쓸 수 있고, 스토어 비용과 심사가 없음.
- **검토했던 대안**: 처음부터 앱(Expo, Flutter, 네이티브). 앱은 화면이 꺼져도 서버 없이 정시에 알림이 울리는 장점이 있지만, 스토어 비용(Apple 연 $99, Google 1회 $25), 심사, Google Play 신규 계정의 비공개 테스트(테스터 12명, 14일) 부담이 있음.
- **나중에 앱이 필요해지면**: 웹 코드를 Capacitor로 앱으로 포장하고 로컬 알림을 추가.

### 휴대폰 지원: 반응형 + 화면 꺼짐 방지 (2026-11-07)
- 휴대폰 화면 대응은 **반응형 디자인(CSS)** 으로 함. PWA와는 별개.
- 휴대폰은 화면이 꺼지거나 다른 앱으로 넘어가면 웹페이지 실행을 멈춤 → 종료 알림이 제때 안 울릴 수 있음. 그래서 MVP는 "화면을 켜둔 채로 쓰는" 경우를 기본으로 보고, 타이머 진행 중 **Screen Wake Lock**으로 화면 꺼짐을 막음.
- 남은 시간은 종료 시각 기준으로 계산하므로 다시 돌아오면 정확하게 보임.

### PWA: v1.5에서 적용 (2026-11-07)
- 얻는 것: 홈 화면 설치, 주소창 없는 앱 화면, 오프라인 실행, **iPhone 알림**(iOS는 홈 화면에 설치한 웹앱에만 알림 허용, iOS 16.4 이상).
- PWA로도 화면 꺼진 상태의 정시 알림은 해결되지 않음. 해결하려면 서버 푸시가 필요 → 검토 대상(v3 이후).

### 계정: 로그인 없음, 브라우저 저장 (2026-11-07)
- 설정, 할 일, 기록은 localStorage에 저장. 참고 사이트와 같은 방식으로 진입 장벽을 없앰.

### 기술 스택: Next.js + TypeScript (2026-11-07)
- **이유**: 나중에 로그인, 웹 푸시, 함께 집중하기 같은 서버 기능을 같은 프로젝트 안에서 만들 수 있고, 공개 서비스일 때 검색 노출과 Vercel 배포에 유리함.
- **주의**: 타이머, 할 일 화면은 클라이언트 컴포넌트(`"use client"`)로 만듦. localStorage 값(설정, 테마)이 첫 화면에서 서버 렌더링과 달라 깜빡이는 문제(hydration 불일치)를 처음부터 처리함.
- **검토했던 대안**: React + Vite. MVP만 보면 더 가볍지만, 서버 기능을 붙일 때 별도 서버나 BaaS가 필요함.

### 코드 저장소: GitHub 공개 (2026-11-07)

### 배포: 지금은 하지 않음 (2026-11-07)
- MVP 개발이 어느 정도 진행된 뒤 배포. 배포처는 그때 Vercel을 우선 검토.

### 마스코트: 까미 (검정색 푸들) (2026-11-07)
- 뽀모도로 이미지, 로고, 서비스 이름을 까미와 연결함.

### 서비스 이름: 까미도로 / Kkamidoro (2026-11-07)
- 까미 + 뽀모도로. "도로(길)"로도 읽혀서 "휴식 = 까미 산책" 컨셉과 연결됨.
- 영문은 로마자 표기법대로 **Kkamidoro**. `Kamidoro`는 일본어 kami(신, 종이)와 검색 결과가 섞여서 제외.
- 검색으로 같은 이름의 서비스는 확인되지 않음.

### 프로젝트 기본 구성 (2026-11-07)
- **App Router**, **Tailwind CSS**, **ESLint**, **npm**, 코드는 `src/` 폴더 안에 둠 (`docs/`와 분리)
- 설치 방법: [05-setup.md](./05-setup.md)

## 미정

| 항목 | 선택지 | 제안 |
|---|---|---|
| 사용 대상 | 나 혼자 / 공개 서비스 | 공개 서비스 (Next.js를 고른 이유와 맞음) |

| 항목 | 선택지 | 제안 |
|---|---|---|
| UI 컴포넌트 | 직접 만들기 / shadcn/ui | **shadcn/ui** (설정 창, 팝업 등을 빠르게, 코드가 프로젝트에 복사되어 수정 자유로움) |

| 테스트 | 없음 / Vitest | **Vitest** (타이머 시간 계산 로직만이라도 테스트) |
