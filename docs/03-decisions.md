# 결정 기록

개발하면서 내린 결정과 그 이유를 모아두는 문서입니다. 결정이 바뀌면 기존 내용을 고치고 "변경 이력"에 남깁니다.

## 결정됨

### 플랫폼: 웹 (2026-11-07)
- **이유**: 가장 빠르게 만들어 바로 쓸 수 있고, 스토어 비용과 심사가 없음.
- **검토했던 대안**: 처음부터 앱(Expo, Flutter, 네이티브). 앱은 화면이 꺼져도 서버 없이 정시에 알림이 울리는 장점이 있지만, 스토어 비용(Apple 연 $99, Google 1회 $25), 심사, Google Play 신규 계정의 비공개 테스트(테스터 12명, 14일) 부담이 있음.
- **나중에 앱이 필요해지면**: 웹 코드를 Capacitor로 앱으로 포장하고 로컬 알림을 추가.

### 휴대폰 지원: 반응형 + 화면 꺼짐 방지 (2026-11-07)
- 휴대폰 화면 대응은 **반응형 디자인(CSS)** 으로 함. PWA와는 별개.
- 휴대폰은 화면이 꺼지거나 다른 앱으로 넘어가면 웹페이지 실행을 멈춤 → 종료 알림이 제때 안 울릴 수 있음. 그래서 MVP는 "화면을 켜둔 채로 쓰는" 경우를 기본으로 보고, 타이머 진행 중 **Screen Wake Lock**으로 화면 꺼짐을 막음.
- 남은 시간은 종료 시각 기준으로 계산하므로 다시 돌아오면 정확하게 보임.

### PWA: v1.5에서 적용 (2026-11-07)
- 얻는 것: 홈 화면 설치, 주소창 없는 앱 화면, 오프라인 실행, **iPhone 알림**(iOS는 홈 화면에 설치한 웹앱에만 알림 허용, iOS 16.4 이상).
- PWA로도 화면 꺼진 상태의 정시 알림은 해결되지 않음. 해결하려면 서버 푸시가 필요 → 검토 대상(v3 이후).

### 계정: 로그인 없음, 브라우저 저장 (2026-11-07)
- 설정, 할 일, 기록은 localStorage에 저장. 참고 사이트와 같은 방식으로 진입 장벽을 없앰.

### 기술 스택: Next.js + TypeScript (2026-11-07)
- **이유**: 나중에 로그인, 웹 푸시, 함께 집중하기 같은 서버 기능을 같은 프로젝트 안에서 만들 수 있고, 공개 서비스일 때 검색 노출과 Vercel 배포에 유리함.
- **주의**: 타이머, 할 일 화면은 클라이언트 컴포넌트(`"use client"`)로 만듦. localStorage 값(설정, 테마)이 첫 화면에서 서버 렌더링과 달라 깜빡이는 문제(hydration 불일치)를 처음부터 처리함.
- **검토했던 대안**: React + Vite. MVP만 보면 더 가볍지만, 서버 기능을 붙일 때 별도 서버나 BaaS가 필요함.

### 배포: 지금은 하지 않음 (2026-11-07)

### 마스코트: 까미 (검정색 푸들) (2026-11-07)
- 뽀모도로 이미지, 로고, 서비스 이름을 까미와 연결함.

### 서비스 이름: 까미도로 / Kkamidoro (2026-11-07)
- 까미 + 뽀모도로. "도로(길)"로도 읽혀서 "휴식 = 까미 산책" 컨셉과 연결됨.
- 영문은 로마자 표기법대로 **Kkamidoro**. `Kamidoro`는 일본어 kami(신, 종이)와 검색 결과가 섞여서 제외.
- 검색으로 같은 이름의 서비스는 확인되지 않음.

### 프로젝트 기본 구성 (2026-11-07)
- **App Router**, **ESLint**, **npm**, 코드는 `src/` 폴더 안에 둠 (`docs/`와 분리)
- 설치 방법: [05-setup.md](./05-setup.md)

### 스타일: SCSS 직접 작성 (2026-11-07)
- Tailwind CSS는 쓰지 않음. **SCSS + CSS Modules**(`*.module.scss`)로 컴포넌트마다 스타일 파일을 둠.
- 색상은 CSS 변수(`--color-*`)로 정의 → 다크 모드를 실행 중에 바로 전환 가능. 화면 크기 기준점과 공통 mixin은 SCSS로 관리.
- 구조는 [05-setup.md](./05-setup.md)의 "스타일 구조" 참고.

### UI 컴포넌트, 아이콘: 직접 만들기 (2026-11-07)
- shadcn/ui 같은 UI 라이브러리와 lucide 같은 아이콘 라이브러리를 쓰지 않고 직접 만듦. 까미도로만의 디자인을 자유롭게 하기 위함.
- 공통 컴포넌트는 `src/components/ui/`, 아이콘은 `src/components/icons/`에 두고 재사용. 목록은 [05-setup.md](./05-setup.md) 참고.
- 팝업(설정 창, 완료 팝업)은 ESC로 닫기, 바깥 클릭으로 닫기, 포커스 가두기 같은 접근성 처리를 직접 챙겨야 함. HTML 기본 `<dialog>` 요소를 쓰면 상당 부분 해결됨.

### 코드 포맷: Prettier (2026-11-07)
- 기본 설정 그대로 사용.
- ESLint와 규칙이 겹치지 않게 `eslint-config-prettier` 적용.
- `docs/`는 직접 쓰는 문서라 포맷 대상에서 제외.

### 통계, 배경음: v1.5에서 개발 (2026-11-07)
- MVP에는 넣지 않음. 단, 통계를 위해 MVP부터 세션 기록을 날짜와 함께 저장함.

### 할 일: MVP에 포함 (2026-11-07)
- 할 일 추가, 수정, 삭제, 완료 체크, 집중할 할 일 선택, 할 일별 뽀모도로 개수.

### 한글 폰트: Pretendard (2026-11-07)
- Geist에는 한글이 없어서 OS마다 다른 폰트로 보이던 문제를 해결. npm 패키지의 가변 폰트를 `next/font/local`로 적용 (구글 폰트 사용 안 함).

### 도입하지 않은 도구 (2026-11-07)

| 도구 | 이유 |
|---|---|
| lucide-react | 아이콘 직접 제작 |
| Husky, lint-staged, commitlint | 지금은 사용 안 함. 커밋 형식 실수가 잦으면 재검토 |
| Zod | 보류. 저장 데이터 구조가 정해지면 재검토 |
| Biome | ESLint + Prettier를 이미 설정함. Next.js 전용 ESLint 규칙도 ESLint에만 있음 |
| IndexedDB (Dexie 등) | 세션 기록은 하루 수십 건 수준이라 localStorage로 충분 |
| Temporal API, 날짜 라이브러리 | 브라우저 지원이 고르지 않음. 날짜는 기본 `Date`와 `Intl`로 충분 |
| Web Worker 타이머 | 종료 시각 기준 계산이라 필요 없음 |
| React Compiler | 지금 규모에선 효과가 작고 빌드에 Babel이 추가됨. 성능 문제가 생기면 재검토 |

### 공개 범위: 1단계 (2026-11-07)
- 누구나 주소로 접속해서 쓰는 웹사이트. 로그인 없음, 데이터는 각자 브라우저에 저장, 개인정보를 받지 않음.
- 할 일: 검색·공유용 메타 정보(제목, 설명, 링크 미리보기 이미지), 주요 브라우저와 휴대폰 지원, 피드백 받을 곳.
- 2단계(계정·동기화)부터는 서버, 보안, 개인정보처리방침 등 개인정보 관련 의무가 생김. 3단계는 수익화.

### 상태 관리: Zustand (2026-11-07)
- 타이머, 설정, 할 일, 기록을 store로 관리하고 `persist`로 localStorage에 저장.

### 테스트: Vitest (2026-11-07)
- 타이머 계산 등 순수 로직을 `*.test.ts`로 테스트. 가짜 시계로 시간을 건너뛰어 검증.
- Vitest 5가 **Node.js 22.12 이상**을 요구해서 프로젝트의 Node 최소 버전을 22.12로 올림 (`package.json`의 `engines`).

### 타이머 세부 규칙 (2026-11-07)
- 남은 시간은 "끝나는 시각 - 현재 시각"으로 계산. 다른 탭에 있거나 새로고침해도 정확함.
- 집중 완료 → 짧은 휴식. 이번 사이클 집중이 긴 휴식 주기(기본 4)에 닿으면 긴 휴식. 긴 휴식이 끝나거나 건너뛰면 사이클 처음부터.
- **리셋, 건너뛰기, 모드 탭 전환은 완료로 세지 않음.** 진행 중이거나 멈춘 세션이 있을 때 모드 탭을 누르면 확인 팝업을 띄움.
- 자동 시작이 켜져 있으면 다음 세션이 이전 세션이 끝난 시각부터 이어서 진행됨.
- **자리를 비운 사이 끝난 경우**: 끝난 세션 1개만 완료로 기록. 다음 세션까지 이미 끝났을 시간이면 시작 전 상태로 둠 (자리를 비운 동안 뽀모도로가 저절로 쌓이지 않게).
- 설정을 바꾸면 시작 전 세션에만 바로 반영. 진행 중인 세션은 그대로.
- 끝까지 마친 세션은 모두(휴식 포함) 날짜와 함께 기록. "오늘"은 기기 시간 기준 자정부터.
