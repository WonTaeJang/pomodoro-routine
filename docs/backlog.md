## 처리 규칙

- 독립적으로 추적할 기능·버그를 등록합니다. 같은 작업의 문구·포맷·문서 보완은 별도 항목으로 쪼개지 않습니다.
- 번호는 완료 목록까지 포함해 이어서 매기며 재사용하지 않습니다. 현재 마지막 번호는 `I-053`, `B-013`입니다.
- `열림` → `진행 중` → 구현·필요한 검증 후 `완료`. 미루기로 한 작업은 `보류`와 이유를 남깁니다.
- 목적·완료 조건·상태·우선순위를 기본으로 쓰고, 버그 재현 방법과 의존성·미정 사항은 필요한 만큼만 덧붙입니다. 우선순위는 높음(사용 지장)·보통·낮음입니다.
- 완료 항목은 이 파일에서 빼고 완료 목록에 결과 한 줄을 남깁니다. 커밋·버전은 이미 알 때만 적으며, 해시를 채우기 위한 후속 커밋은 만들지 않습니다.
- 관련 테스트·문서·백로그 상태는 구현과 같은 커밋에 포함합니다. 커밋 보류 요청이 있으면 검증 여부와 미커밋 상태를 구분해 적습니다.
- 확정 설계는 결정 문서, 구현 방법은 해당 구현 문서에 둡니다. 백로그에는 링크와 남은 일만 남기며 버전 규칙은 여기서 중복 정의하지 않습니다.

### I-052 · 집중 소리에 맞춘 은은한 타이머 애니메이션

- 상태: 진행 중
- 우선순위: 보통
- 목적: 집중 소리가 나오는 동안 타이머 원(까미 사진이 있는 링) 안팎에 그 소리 분위기에 맞는 은은한 움직임을 넣어, 소리가 화면으로도 느껴지게 한다.
- 완료 조건:
  - 집중 소리가 **실제로 재생 중일 때만** 보인다(`useFocusSoundPlaying`). 골라만 둔 상태·휴식·일시정지·끄기에서는 서서히 사라진다.
  - 소리별 애니메이션 (제안):
    - 백색·핑크·브라운 노이즈: 링에서 퍼져 나가는 옅은 물결 고리. 백색은 잘고 빠르게, 핑크는 부드럽게, 브라운은 느리고 깊게.
    - 빗소리: 링 위로 떨어지는 가는 빗줄기와 작은 물방울 파문. 창가 빗소리: 링 표면을 타고 흘러내리는 물방울.
    - 모닥불: 링 아래쪽의 따뜻한 빛 일렁임과 위로 떠오르는 불티.
    - 숲속: 천천히 떨어지는 나뭇잎 몇 장.
    - 파도: 링 아래쪽에 잔잔히 출렁이는 물결선.
    - 비행기 기내: 링 뒤로 천천히 흘러가는 구름.
    - 도서관·카페(I-029, 추가되면): 책장 넘김 / 커피잔 김.
    - 랜덤: 이번 집중에 고른 소리의 애니메이션.
  - **은은하게:** 낮은 투명도, 느린 속도, 개수 적게. 남은 시간 숫자·까미 사진·진행 띠를 가리지 않고, 마지막 구간 빛(`glow`)·완료 축하(`Celebration`) 효과와 겹치면 그쪽을 우선.
  - "움직임 줄이기"면 움직이지 않는 장식만 두거나 끈다. 설정의 링 효과(`ringEffects`)를 끄면 함께 꺼진다.
  - 탭이 안 보일 때는 멈춰서 배터리·CPU를 아낀다. 휴대폰에서도 버벅이지 않게 CSS 애니메이션(transform·opacity) 위주, 필요하면 작은 캔버스.
  - 밝은/어두운 테마 모두에서 어울리는 색(모드 강조색 기반).
- 참고:
  - 코드: `src/features/timer/components/TimerRing.tsx`(링·효과 묶음, `effects`·`glow`·`Celebration`), `src/components/ui/ProgressRing`, `src/features/focus-sound/useFocusSoundPlaying.ts`, 소리 목록 `src/features/focus-sound/sounds.ts`(소리별 애니메이션 종류를 여기에 붙이면 소리 추가 시 함께 관리).

- 현재 (2026-11-14): 시안(소리별 움직임, 모닥불은 강하게) 확정 후 9개 소리 모두 적용. `SoundAmbience`(타이머 링 뒤 `ProgressRing` `underlay`), 소리→분위기 표(`AMBIENCE`, 소리를 추가하면 타입 오류로 알려 줌), 들리는 소리는 재생기의 `getAudibleFocusSound`(랜덤이면 이번 소리, 미리 듣기 포함). CSS 애니메이션만 사용, 조각 위치는 정해진 난수. 링 효과를 끄거나 마지막 구간 빛이 나면 숨김, "움직임 줄이기"면 멈춘 옅은 장식.

  - **모아 보기:** 받은 뱃지와 아직 못 받은 뱃지(흐리게, 조건과 진행도 표시 예: 7일 연속 중 4일)를 한 화면에서. 위치 후보: 프로필, 캘린더(통계) 페이지, 헤더 메뉴의 "뱃지".
  - **처음 도입할 때:** 이미 쌓인 집중 기록으로 계산해 그동안 달성한 뱃지를 한 번에 준다 (이때는 알림을 한꺼번에 띄우지 말고 "그동안 N개를 모았어요" 한 번).
  - 뱃지 그림은 까미 테마(발바닥, 까미 표정 등)로 통일, 밝은/어두운 테마 모두. 이름·설명은 ko/en.
  - (선택) 수료증 칭호: 대표 뱃지 하나를 골라 수료증에 칭호로 넣기.
- 참고:
  - 계산 재료: 집중 기록 `src/features/history/`, 통계 `src/features/stats/`, 할 일 `src/features/tasks/`, 수료증 `src/features/certificate/`. 뱃지 조건은 기록에서 다시 계산할 수 있게 순수 함수로 두고, 받은 날짜만 따로 저장.
