# 뽀모도로 기법이란?

## 한 줄 요약

일을 **25분 집중 + 5분 휴식** 단위로 쪼개서, 집중력을 유지하고 내가 일에 들인 시간을 눈으로 확인할 수 있게 하는 시간 관리 방법입니다.

## 유래

- 1980년대 후반, 이탈리아의 대학생이던 **프란체스코 시릴로(Francesco Cirillo)** 가 공부에 집중하려고 만든 방법입니다.
- 토마토 모양의 주방 타이머를 썼기 때문에 이탈리아어로 토마토를 뜻하는 **"뽀모도로(Pomodoro)"** 라는 이름이 붙었습니다.
- 25분 집중 한 번을 **"1 뽀모도로"** 라고 부릅니다.

## 기본 진행 방식

1. 할 일을 하나 고릅니다.
2. 타이머를 **25분**에 맞추고 그 일에만 집중합니다.
3. 타이머가 울리면 **5분 짧은 휴식**을 합니다.
4. 이 과정을 반복하고, **뽀모도로 4번마다 15~30분 긴 휴식**을 합니다.

```
[집중 25] → [휴식 5] → [집중 25] → [휴식 5] → [집중 25] → [휴식 5] → [집중 25] → [긴 휴식 15~30]
                                                                              ↑ 4번째 집중 후
```

## 핵심 원칙

- **뽀모도로는 쪼갤 수 없다**: 중간에 멈추면 그 뽀모도로는 완료로 치지 않습니다. 반쯤 한 뽀모도로는 없습니다.
- **방해 관리**: 집중 중에 떠오른 다른 생각이나 요청은 바로 처리하지 않고 메모해 두었다가 휴식 시간이나 다음 뽀모도로에 처리합니다.
- **휴식은 진짜 휴식**: 휴식 시간에는 일과 관련된 것을 하지 않고 자리에서 일어나거나 눈을 쉬게 합니다.
- **기록하고 돌아보기**: 하루에 뽀모도로를 몇 개 했는지 기록하면, 일에 드는 시간을 점점 더 정확하게 예측할 수 있게 됩니다.

## 왜 효과가 있나

- 시간 제한이 있어서 시작하기가 부담스럽지 않습니다. ("25분만 해보자")
- 휴식이 정해져 있어서 오래 일해도 덜 지칩니다.
- 완료한 뽀모도로 개수가 눈에 보여서 성취감이 생깁니다.

## 우리 앱에 주는 의미

| 원칙 | 앱 기능으로 옮기면 |
|---|---|
| 25 / 5 / 15 사이클 | 집중 → 휴식 → 긴 휴식을 자동으로 이어주는 타이머 |
| 타이머가 울린다 | 종료 알림 (소리, 브라우저 알림) |
| 4번마다 긴 휴식 | 완료 횟수를 세서 자동으로 긴 휴식 전환 |
| 쪼갤 수 없다 | 중간에 리셋하거나 건너뛰면 완료로 세지 않음 |
| 기록하고 돌아보기 | 오늘 완료한 뽀모도로 개수 표시 → 나중에 통계로 확장 |
| 할 일을 고른다 | 할 일 목록 / 루틴 기능 → MVP 이후 확장 후보 |
