# 참고 사이트 분석: PomodoTree

- 주소: https://www.pomodotree.com/
- 분석일: 2026-11-07

## 화면 구성

- 상단: 로고, 🔥 연속 일수, 언어 선택, 🌙 테마 전환, ⚙️ 설정
- 탭: **⏱ Timer** / **📊 Analytics**
- Timer 탭: 모드 탭(🎯 Focus / ☕ Short Break / 🌿 Long Break) → 큰 숫자 타이머 → 버튼(↺ 리셋, ▶ 시작/일시정지, ⏭ 다음) → 📋 Tasks 패널 → 🎵 배경음

## 기능 목록

| 분류 | 기능 |
|---|---|
| 타이머 | 집중 / 짧은 휴식 / 긴 휴식, 리셋, 시작/일시정지, 다음 세션으로 건너뛰기, "긴 휴식 주기(N회마다)" 설정 |
| 설정 | 각 모드 시간(분), 휴식 자동 시작, 집중 자동 시작, 브라우저 알림 켜기, 설정 저장, 데이터 초기화 |
| 할 일 | 할 일 추가, 할 일별 완료 뽀모도로 개수 기록 |
| 통계 | 오늘 세션 수 / 집중한 분, 연속 일수(streak), 누적 세션 / 시간, 주간 집중 세션 차트 |
| 게임화 | 🔥 연속 일수, 🏆 업적 배지 |
| 배경음 | 빗소리, 숲, 카페, 백색소음 (오디오 파일 없이 브라우저에서 생성), 볼륨 조절 |
| 알림 | 브라우저 알림, 완료 팝업("Session Complete!" + 다음 단계로 가는 버튼) |
| 단축키 | Space 시작/일시정지, R 리셋, N 다음, S 설정 |
| 테마 | 다크 / 라이트 |
| 언어 | 25개 언어 |
| 계정 | 로그인 없음, 데이터는 브라우저에 저장 |
| 설치 | PWA (홈 화면 설치, 오프라인) |
| 기타 | 브라우저 확장 프로그램 (사이트 차단 등, 유료 기능 있음) |

## 배울 점

- **로그인 없이 바로 시작**: 진입 장벽이 없음. 데이터는 브라우저에 저장.
- **완료 팝업에 다음 행동 버튼**: "☕ Short Break →" 처럼 다음 단계로 바로 이어짐.
- **단축키**: PC에서 쓰기 편함. 구현 부담도 작음.
- **배경음을 파일 없이 생성**: Web Audio API로 노이즈를 만들면 용량과 저작권 걱정이 없음.

## 우리가 다르게 갈 점

- PomodoTree에는 **루틴** 기능이 없음 → 우리 프로젝트의 차별점으로 삼을 수 있음.
- 확장 프로그램, 25개 언어는 범위가 너무 큼 → 제외.
